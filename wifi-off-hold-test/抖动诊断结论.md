# 舵机静止抖动 · 诊断结论

## 现象
- 5 个舵机都能独立动，但静止锁定时有 2-3 个（实际所有）舵机小幅抽搐，**不同步**。
- 不承重（空载）也抖。

## 排除过的原因
| 怀疑对象 | 结论 |
|---|---|
| PCA9685 板 | 已拆、改直驱（arm-5servo）后仍抖 → 排除 |
| 舵机个体坏（电位器/死区） | 全部都会抖 → 排除"个别坏件" |
| 电压不足 / UBEC | 5V 20A 余量充足；空载也抖 → 排除欠压临界振荡 |
| 机械虚位 / 负载 | 空载也抖 → 排除 |

## 确诊方法（决定性实验）
烧录 `wifi-off-hold-test.ino`：**不开 WiFi，纯硬件 PWM 锁死 5 舵机**。
结果：**完全不抖**。

## 根因
**ESP32 的 WiFi 射频（含地弹）耦合进未屏蔽的信号线。**
静止时固件不再写 PWM，信号本是一条恒定脉宽；WiFi 发包瞬间的 RF 毛刺耦合进信号线，被模拟舵机当成一次微小角度变化 → 抽搐。不同舵机/不同时刻耦合强度不同 → 看起来"异步、小幅"。

## 整改清单（保留 WiFi 的前提下，按性价比排序）
1. **走线（零成本，最有效）**
   - 信号线尽量短，不要和 5V/12V 电源线并排长距离走。
   - 5 根信号线别抱成一束，能分开就分开。
   - ESP32（尤其板载天线一端）与舵机线束保持 ≥5cm 距离。
2. **地线星形接地**
   - 以 UBEC 输出端为唯一星点：UBEC GND / ESP32 GND / 分电盒 GND 三点在此汇合。
   - 不要让 ESP32 的回流电流走舵机的地线；加粗这根公共地。
3. **信号末端滤波**
   - 保留每根信号线 100Ω 串阻（磨圆边沿）。
   - 在**每只舵机的信号输入端对地**并联 1–4.7nF 电容，把 2.4GHz 射频滤掉（不影响 50Hz 脉宽）。
4. **软件配合**：如需更高定位精度，可在固件 loop 里周期性重写当前目标角，RF 偶发扰动后立即拉回目标。

## 复查方法
整改后烧录**完整版（含 WiFi/网页）**固件，静止 30 秒确认不再抽搐，再进入动作测试。

## 延伸（如果以后要彻底免疫这类抖动）
串行总线闭环舵机（如 Feetech STS3215 / STS3032）走总线协议 + 自带反馈，不依赖模拟 PWM 脉宽，天然免疫此类 RF 抖动，还能回传角度/电流做力反馈。预算允许可作为下阶段升级（见对话中的方案 B）。
