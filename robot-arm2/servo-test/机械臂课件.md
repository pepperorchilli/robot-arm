# 4舵机代码 · 保姆级讲解

## 1. PWM 控制舵机的原理

舵机里面有个小电路板，它不看电压高低，只看**橙线上高电平持续了多久**。

```
高电平持续 0.5 毫秒 → 舵机转到 0°
高电平持续 1.5 毫秒 → 舵机转到 90°
高电平持续 2.5 毫秒 → 舵机转到 180°
```

画出来就是这样：

```
0°:
████░░░░░░░░░░░░░░░░░░  0.5ms 高电平，剩下 19.5ms 低电平

90°:
██████████░░░░░░░░░░░░  1.5ms 高电平，剩下 18.5ms 低电平

180°:
██████████████████░░░░  2.5ms 高电平，剩下 17.5ms 低电平

|←──────── 20ms ───────→|  每 20ms 循环一次，1秒 50次 = 50Hz
```

你代码里对应的就是这两行：

```cpp
const int MIN_PULSE   = 500;   // 0°  时脉宽 500 微秒 = 0.5 毫秒
const int MAX_PULSE   = 2500;  // 180°时脉宽 2500 微秒 = 2.5 毫秒
```

**记一句话：脉宽越宽，转角越大。0.5ms → 0°，2.5ms → 180°，中间是线性的。**

## 2. 信号和电源是两回事

舵机的三根线，干的活不一样：

```
红线 (VCC) ─→ 供电  ┐
棕线 (GND) ─→ 回路  ├── 这俩走的是"力量"（大电流）
橙线 (SIG) ─→ 信号  ─── 这根走的是"信息"（小信号）
```

```
┌─────────────────────────────────────────┐
│                                         │
│   ESP32                     外部电源     │
│  ┌──────┐                ┌──────────┐  │
│  │ GPIO ├──→ 橙线(SIG) →│  舵机    │  │
│  │  GND ├──→ 共地 ────→│  红线 ← 外部电源+ │
│  └──────┘               │  棕线 ← 外部电源− │
│                         └──────────┘  │
│                                         │
│   ESP32 负责"说"（只发信号，不费电）      │
│   外部电源负责"干"（出力气）              │
└─────────────────────────────────────────┘
```

**ESP32 的 5V 引脚最多出 500mA 电流。一个 MG996R 舵机负载时就要 700-900mA，4个同时动要 10A。从 ESP32 取电 = 烧板子。**

## 3. 必须共地

```
正确 ✅                      错误 ❌

外部电源− ─┬─ 舵机棕线        外部电源− ── 舵机棕线
           ├─ ESP32 GND       ESP32 GND ── 悬空！
           │                  （什么都没接）
         两边的 GND 连在一起
```

**为什么必须连：**

ESP32 发信号，靠的是 "GPIO 和 GND 之间的电压差"。如果两边的 GND 没连在一起，舵机那边不知道你的"高电平"是相对于谁的高电平。

**类比：两个人量身高。你站在一楼量是 175cm，但另一个人站在三楼量，基准不一样，数字就全乱了。共地 = 两个人都站同一层楼。**

## 4. setup() 和 loop()

Arduino / ESP32 程序永远是这个结构：

```
程序启动
   │
   ▼
setup()  ← 只跑一次。初始化硬件、WiFi、舵机
   │
   ▼
loop()   ← 不断重复。处理网页请求、读传感器
   │
   └──→ loop() → loop() → loop() → ... 永远循环
```

你代码里：

```cpp
void setup() {
  // 初始化舵机、开 WiFi、启动 Web 服务器
  // 这些事只需要做一次
}

void loop() {
  server.handleClient();  // 检查有没有人访问网页，有就处理
}
```

## 5. 舵机初始化的三行代码

```cpp
servos[i].setPeriodHertz(50);                            // ① 设 PWM 频率 = 50Hz
servos[i].attach(servoPins[i], MIN_PULSE, MAX_PULSE);    // ② 绑到 GPIO，设脉宽范围
servos[i].write(currentAngle[i]);                        // ③ 转到初始角度 90°
```

**逐行解释：**

**① setPeriodHertz(50)** — "我要发 50Hz 的 PWM 信号"
- 50Hz = 每秒 50 个脉冲 = 每个周期 20ms
- 模拟舵机的标准频率，改了这个数舵机可能不认

**② attach(GPIO, 500, 2500)** — "用这个 GPIO 发信号，0°=500μs，180°=2500μs"
- 调用 attach 之后，GPIO 开始持续输出 PWM
- 舵机收到信号，开始受力锁住当前位置

**③ write(90)** — "转到 90°"
- 库自动算出 90° 对应 1500μs 脉宽
- 舵机收到 1500μs 脉冲 → 转到 90° 并停住

**这三行的顺序不能乱：先设频率 → 再绑引脚 → 最后写角度。**

## 6. HTTP 请求控制舵机的过程

你的手机浏览器访问 `http://192.168.4.1/set?servo=0&angle=45` 时：

```
手机浏览器                         ESP32
    │                                │
    │  GET /set?servo=0&angle=45     │
    │ ─────────────────────────────→ │
    │                                │  解析: servo=0, angle=45
    │                                │  constrain 检查范围
    │                                │  算出 PWM 脉宽
    │                                │  舵机 0 转到 45°
    │                                │
    │ ←───────── 45 ─────────────── │  返回当前角度
```

**你项目里有三个 URL：**

| URL | 干什么 |
|------|------|
| `http://192.168.4.1/` | 返回控制网页 |
| `http://192.168.4.1/angles` | 返回 4 个舵机的角度 `[90,45,30,120]` |
| `http://192.168.4.1/set?servo=0&angle=45` | 把舵机 0 转到 45° |

**关键认知：任何能发 HTTP 请求的东西都能控制你的机械臂——Python 脚本、手机 App、命令行……不只是那个网页。**

## 7. constrain() — 安全阀门

```cpp
int idx    = constrain(server.arg("servo").toInt(), 0, 3);
int target = constrain(server.arg("angle").toInt(), 0, 180);
```

如果有人恶意输入 `/set?servo=999&angle=500`：

```
没有 constrain:  servos[999].write(500) → 数组越界 → 程序崩溃
有 constrain:    idx=3, target=180 → 安全执行
```

**constrain(值, 最小, 最大)：超过最大就取最大，低于最小就取最小。**

## 8. 数组从 0 开始

```cpp
const int servoPins[4] = {13, 12, 14, 15};

servoPins[0] = 13   // 第 1 个舵机（底座）
servoPins[1] = 12   // 第 2 个舵机（大臂）
servoPins[2] = 14   // 第 3 个舵机（小臂）
servoPins[3] = 15   // 第 4 个舵机（手腕）
```

几乎所有编程语言数组都从 0 开始数。习惯它。

## 9. 平滑移动的代码

```cpp
int step = (target > currentAngle[idx]) ? 3 : -3;

while (abs(currentAngle[idx] - target) >= 3) {
    currentAngle[idx] += step;
    servos[idx].write(currentAngle[idx]);
    delay(25);
}
```

**人话翻译：**

1. 目标在当前位置的哪边？右边就走 +3°，左边就走 −3°
2. 只要离目标还差 3° 以上，就走一步，歇 25 毫秒
3. 循环往复，直到离目标不到 3°
4. 最后一步精确到位

**为什么不直接 `servo.write(目标)` 一步到位？**

直接跳过去 = 舵机瞬间全速转 = 机械臂会猛地甩过去。一步步走 = 平滑运动。代价是花的时间更长、耗电更多。

**步长 3° 和 delay(25) 是平衡点：既不太抖、也不太慢、也不让电源压力太大。**

## 10. WiFi AP 模式

```cpp
WiFi.softAP(ssid, password);
```

AP = Access Point = 热点。ESP32 自己变成一个微型路由器。

- 不需要家里有 WiFi
- 不需要路由器
- 手机直接连 ESP32 的 WiFi
- IP 地址固定是 `192.168.4.1`（记死这个地址）

## 11. 串口

```cpp
Serial.begin(115200);
```

ESP32 通过 USB 线跟你电脑聊天。你打开 Arduino IDE 的串口监视器就能看到打印的信息。

**115200 是波特率（通信速度），串口监视器必须选同一个数字，否则显示乱码。**
