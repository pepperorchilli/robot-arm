## 打印参数

官方基准：

- 材料 **PLA+**
- 0.4mm 喷嘴 / 0.2mm 层高，或 0.6mm 喷嘴 / 0.4mm 层高
- 填充 **15%**
- 支撑开 everywhere，但忽略与水平夹角大于 45° 的斜面
- **水平轴的螺丝孔里不能有支撑**

针对「结实稳固」的调整：上表标「是」的承力件填充提到 **30%**、壁厚 **4 圈**；
其余件保持 15%。承力件占了大头（402 / 571 cm³，约 70%），所以整机不会重多少，
但关节孔位不容易被舵机力矩拉裂——这是 SO-ARM 用 PLA 最常见的失效点。

**耗料预估**：15% 全件 ≈ 300–370g；承力件 30% ≈ 390–480g。备 1kg 一卷有余量。

### 电源方案（C047 版）

C047 工作范围 **4~14V**，所以 **3S 锂电满电 12.6V 可以直通舵机总线，不需要降压**。

```
  Mac ──USB──▶ ESP32-S3      ← 5V 供电 + 串口日志，一根线两用
                 │
                 ├─ GPIO17 ─[1kΩ]─┐
                 ├─ GPIO16 ───────┤──▶ 总线 DATA
                 └─ GND ──────────┤
                                  │
 3S 锂电 12.6V ───────────────────┴──▶ 舵机总线（V+ / GND）
```

**ESP32 用电脑 USB 供电**，所以不需要 UBEC 了，电源链只剩"锂电直通舵机"这一路。

### 三条接线铁律

1. **必须共地**。USB 供电时 ESP32 的 GND = 电脑 USB 的 GND，
   **必须接到舵机总线的 GND（电池负极）**。不接的话半双工 TTL 没有共同参考电平，
   表现为扫描时有时通有时不通、回读乱码——最难查的一类故障。
   电池是浮地的，电脑地和电池负极短接无风险。
2. **只从总线引 GND 和 DATA，绝不引 V+**。ESP32 的 5V 脚由 USB 喂，
   灌进 12.6V 会瞬间烧。
3. **上电顺序：先 USB，后电池**。舵机先上电时 DATA 线被舵机驱动，
   会经 GPIO16/17 的保护二极管倒灌进 3.3V 轨，导致 ESP32 起不来 / 连不上 WiFi /
   烧录失败。关机时反过来。

> 脱机演示（不插电脑）时，把 USB 线插到 **5V 充电宝**上即可，日志走 WebSocket 照样能看。
> 一代那个 **UBEC 5V 留着当备选**——两个 5V 源**二选一，别同时接**。

对比一代：一代是 `12.6V → UBEC 降压 → 分电盒 → 5 路 MG996R`，
那几个降压和分电盒都是为了老舵机。**二代换成总线舵机后，这两样都不需要了**——
舵机直通锂电，菊花链一根线串到底。

**如果用墙上电源而不是电池**：需要 **12V 5A+**。
C047 单个堵转电流 **2.7A**，六个关节最坏情况 16.2A。
**别买 12V 2A**——连两个关节同时轻微堵转都扛不住，表现是"一动就重启 / 舵机集体复位"。
按 5A 起买，10A 更稳。（官方 BOM 默认给的是 **5V** 电源，那是配 7.4V 舵机用的，别照点。）

### ⚠️ C001 和 C047 不能混在一条总线上

同一根总线共享电源。**C001 上限 7.4V，接在 12.6V 的总线上会烧。**

所以那颗 C001 只做两件事：
1. 台面练手 —— 熟悉 `servo-tools/bench.py` 的整套流程（**用 5~7.4V**）
2. 以后当备件 / 单独测试件

**C047 到货后，C001 不要接进手臂的总线。**

好在两者**协议、寄存器、减速比（1/345）完全一样**，
台面上学到的每一步都能原样搬到 C047 上，只有电压和 ID 要重设。

### 如果以后想加 Leader

Leader 用的是**另一套 SKU**，别顺手再买 6 个 C047：

- 3 × 1/147 减速比（C046）
- 2 × 1/191 减速比（C044）
- 1 × 1/345 减速比（C001）
- 而且官方注明 **Leader 只能 7.4V**

加 Leader 的主要动机是模仿学习的数据采集——LeRobot 官方的 ACT / SmolVLA
标准流程就是 Leader-Follower 遥操作录演示。没有 Leader 的话，
要用手势控制或网页控制台自己当遥操作源、自己解决到 LeRobot Dataset 的格式对接。
这是偏离官方路线的做法，但可以作为一个创新点写进简历。
