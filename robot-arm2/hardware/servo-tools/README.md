# 阶段一：台面配置舵机（微雪转接板 + Mac）

目标：把一颗舵机接上、确认通信、改好 ID。
这一步是**一次性的**——ID 写进 EEPROM，掉电不丢。六个舵机各做一遍就完了。

## 当前已确认的环境

| 项 | 值 |
|---|---|
| 转接板 | 微雪 Bus Servo Adapter (A) |
| USB 芯片 | CH343P（Vendor ID `0x1a86`） |
| 串口 | **`/dev/cu.usbmodem5B8E1149761`** |
| 驱动 | ✅ **不用装**，macOS 自带 CDC 驱动已认 |
| pyserial | ✅ 已装（3.5） |

> 串口名带 `5B8E114976` 是这块板的序列号，换 USB 口不会变。

---

## ⚠️ 动手前必读：电压

原理图确认过，**舵机电源轨 = DC 输入直通**（转接板上的 H3/H5 直接接 `DC_IN0`）。
板上那套降压只给逻辑供电，不碰舵机。**所以喂多少伏，舵机就吃多少伏。**

| | 电压 |
|---|---|
| 转接板丝印标的输入 | 9 ~ 12.6V |
| **C001** 实际范围 | **4 ~ 7.4V** |

**丝印那个 9~12.6V 是给 C047（12V 版）写的。你现在是 C001，接 12V 会烧。**

👉 **DC 接 5 ~ 7.4V。** 桶形插头是 **5.5×2.1mm 中心正极**，极性反了同样烧。

### 台面测试用什么电源

**直接用一代那套里现成的 UBEC 5V 输出**，接到绿色端子就行（端子能夹裸线，不用桶形插头）。
只测一颗舵机、而且只是设 ID 不使劲，5V 完全够——扭矩在这里无所谓。

> 这颗 C001 是**台面练手件**，最终手臂用的是 **6 颗 C047（12V）**。
> 两者协议和寄存器完全一样，所以这里学到的每一步都能原样搬到 C047 上。
> 但 **C047 到货后，别把这颗 C001 接进手臂的总线**——12.6V 会烧了它。

## 接线

```
   Mac ──USB-C──▶ ┌──────────────┐
                  │  微雪转接板   │─── 3针 ──▶ 舵机
   DC 5~7.4V ───▶ │              │   DC_IN0 / GND / DATA
                  └──────────────┘
```

1. **舵机** 3 针线 → 转接板的**总线口**（H3 或 H5，不是 UART 口）。
   丝印对应：`DC_IN0` / `GND` / `DATA`
2. **USB-C** → Mac（这根只喂板上逻辑 + 提供串口，**不给舵机供电**）
3. **DC 5~7.4V** → 桶形座 或 绿色端子。**最后再接，接完再上电**

> USB 和 DC **必须同时接**。只插 USB 的话舵机没电，扫描会一个都找不到。

## 步骤

先切到工具目录：

```bash
cd "/Users/qiudai/Desktop/机器人研究(vscode)/robot-arm2/hardware/servo-tools"
```

### 第 1 步：确认串口 + 扫描舵机

```bash
python3 bench.py scan
```

- 看到 `✓ 串口已打开` + `✅ 发现舵机：ID = 1` → **接线全对，可以往下走**
- 看到 `一个舵机都没回应` → 按脚本打印的清单逐条排查

### 第 2 步：读状态，确认这颗舵机是好的

```bash
python3 bench.py info /dev/cu.usbmodem5B8E1149761 1
```

会打印位置 / 速度 / 负载 / 电压 / 温度 / 电流。
**重点看电压**——应该和你 DC 输入的电压吻合（比如给 5V，这里就是 ~5.0V）。
对不上说明供电有问题。

### 第 3 步：改 ID

**出厂 ID 全是 1，六颗全一样。必须一个个改。**

```bash
python3 bench.py id /dev/cu.usbmodem5B8E1149761 1 2
```

改完**拔掉 DC 再插回**（让新 ID 生效），然后验证：

```bash
python3 bench.py info /dev/cu.usbmodem5B8E1149761 2
```

### 第 4 步：测转向

```bash
python3 bench.py move /dev/cu.usbmodem5B8E1149761 2 90
```

不动的话先补一条使能扭矩：

```bash
python3 bench.py torque /dev/cu.usbmodem5B8E1149761 2 1
```

### 第 5 步：松力，换下一颗

改 ID 前最好让舵机能自由转动：

```bash
python3 bench.py torque /dev/cu.usbmodem5B8E1149761 2 0
```

然后重复第 1~5 步，把 ID 改成 3、4、5、6。

## 为什么不用官方的 ping.py / change_id.py

官方脚本有两个坑，原样跑一定失败：

1. **`ping.py` 里写 `SCS_ID = 254`** —— 总线上没有这个 ID（有效范围 0~253，你的舵机是 1），
   结果是发出去等回应、超时失败。你会误以为接线错了。
2. **端口硬编码**（`DEVICENAME = 'COM73'`）—— 每换一台电脑就得回去改文件。

`bench.py` 把这两件事都变成参数，端口和 ID 从命令行传，不用改文件。

> 另外官方包里那个 `stservo-env/` 虚拟环境是 **Windows 的**（里面是 `Scripts/python.exe`），
> Mac 上用不了，直接忽略。
